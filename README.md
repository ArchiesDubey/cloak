# Cloak

**Local-First Developer Secrets Manager & Process Injector**

Cloak is designed to eliminate plaintext `.env` files and avoid cloud-vendor lock-in. It stores secrets in your OS-native keyring (macOS Keychain, Windows Credential Manager, Linux Secret Service) or an encrypted file vault, and injects them directly into child process memory on demand.

---

## Key Features

- **Local-First & Zero Plaintext**: Eliminates `.env` files sitting on disk or getting accidentally committed to Git.
- **Universal LLM Agent Integration (`cloak setup`)**: Automatically configures and links Claude Code, Cursor IDE, Antigravity (`agy`), Windsurf, GitHub Copilot, OpenAI Codex, and OpenCLI agents. Agents retrieve credentials securely via Cloak without prompting developers to edit `.env` files.
- **Dynamic Domain Auto-Inference**: Automatically intercepts and injects credentials for *any* arbitrary API domain in-flight without requiring manual routing rules (e.g. `api.pexels.com` -> `PEXELS_API_KEY`, `api.groq.com` -> `GROQ_API_KEY`). Public unauthenticated traffic passes through untouched.
- **Decrypted In-Flight HTTPS Interception**: Uses a locally generated Certificate Authority (`rcgen`) and dynamic leaf signing to decrypt TLS connections in volatile memory, inject required auth headers, and re-encrypt upstream.
- **OS-Native Keyrings & Hardware Access Control**:
  - **macOS**: Apple Keychain Services (`Security.framework`) with batch querying and Touch ID / Secure Enclave hardware access control (`SecAccessControl` with `kSecAccessControlUserPresence` / `kSecAccessControlBiometryAny`).
  - **Windows**: Windows Credential Manager / DPAPI with Local Machine account credential verification via `PrincipalContext`.
  - **Linux**: FreeDesktop Secret Service API (GNOME Keyring / KWallet via D-Bus) with user PAM verification via Polkit (`pkexec`).
- **Headless Fallback**: Standalone encrypted vault file (`--store file`) using **Argon2id** (OWASP/NIST parameters) and **XChaCha20-Poly1305 AEAD** for remote Linux servers and CI/CD pipelines.
- **Process Memory Isolation**: Secrets are passed strictly to the child process's environment block in memory (`cloak run -- <cmd>`). Secrets are **never** passed via CLI arguments (protecting against `ps aux` and `/proc/<pid>/cmdline` snooping) and never leak to the parent shell.
- **Least-Privilege Scoping**: Scope child process access to only the secrets it needs with `cloak run --keys KEY1,KEY2 -- <cmd>`.
- **Screen Leak Prevention**: `cloak get <KEY>` automatically masks credentials (`sk-p••••••••9999`) unless explicitly run with `--reveal`.
- **Universal ZeroizeOnDrop Memory Hardening**: Secrets across the core storage layer (`SecretStore`), process injector (`runner.rs`), and local AI proxy (`proxy/mod.rs`) are held in `zeroize::Zeroizing<String>` buffers, enforcing volatile memory zeroing upon deallocation. Anti-core dump hardening (`RLIMIT_CORE = 0` on Unix) prevents memory extraction via core dumps.
- **Concealed Clipboard Protection**: Copies secrets with concealed pasteboard markers (`org.nspasteboard.ConcealedType`, `org.nspasteboard.AutoGeneratedType`) on macOS to prevent clipboard history monitors (Raycast, Alfred, Maccy, 1Password, Paste) from recording credentials. On Windows and Linux, native clipboard integration is supported via `arboard`. All platforms enforce automatic 30-second clipboard memory wiping guarded by change-count / content comparison so intervening user copies are not destroyed.
- **Desktop HUD & Self-Contained DMG**: Minimalist desktop HUD built with Tauri v2. The shareable `.dmg` automatically installs the CLI symlink and configures all agent rules on first launch.

## Installation & Setup

### Prerequisites
- **Rust Toolchain**: `cargo` & `rustc` (1.78+)
- **Node.js & pnpm**: Node 18+ and `pnpm` 9+ (for building the GUI)
- **Platform Dependencies**:
  - **macOS**: Xcode Command Line Tools (`xcode-select --install`)
  - **Linux**: `libsecret-1-dev`, `libssl-dev`, `libwebkit2gtk-4.1-dev`, `libappindicator3-dev`, `librsvg2-dev`
  - **Windows**: Microsoft C++ Build Tools & WebView2

### 1. Build CLI & Install Globally:
```bash
cargo build --release
cp ./target/release/cloak ~/.cargo/bin/
```

### 2. Desktop GUI Setup:
```bash
cd gui
pnpm install
pnpm run build
```

```bash
cd gui

- **macOS**: `.dmg` installer & `.app` bundle
- **Linux**: `.deb` package & `.AppImage`

On first launch of community builds, grant permission via **Right-click `Cloak.app` -> Open**, or run:

```

## Universal LLM Agent Integration

Configure all local coding agents (Claude Code, Cursor, Antigravity `agy`, Windsurf, Copilot, Codex) with a single command:

```bash
cloak setup
```

This verifies and registers Cloak rules across all agent discovery paths:
- `~/.gemini/GEMINI.md` (Antigravity CLI / `agy`)
- `~/.claude/CLAUDE.md` (Claude Code)
- `~/.cursorrules` & `~/.cursor/rules/cloak.mdc` (Cursor IDE)
- `~/.windsurfrules` (Windsurf IDE)
- `~/.codex/CODEX.md` (OpenAI Codex)
- `~/.copilot/instructions.md` (GitHub Copilot)
- `~/.agents/rules/cloak.md` (OpenCLI / Agents framework)

Whenever an agent requires an API key or token, it queries Cloak directly (`cloak list`, `cloak get <KEY> --reveal`, `cloak run -- <cmd>`) without interrupting the developer to manually export variables or edit `.env` files.

## CLI Usage

### 1. Store a Secret
```bash
# Provide value directly:
cloak set OPENAI_API_KEY sk-proj-123456789

# Protect secret with Touch ID / Secure Enclave hardware access control (macOS):
cloak set --touch-id PROD_MASTER_KEY

# Or omit the value to be prompted with secure, masked stdin (no terminal echo):
cloak set AWS_SECRET_ACCESS_KEY
```

### 2. Run Any CLI Tool with Injected Secrets
Secrets are fetched on demand and passed exclusively to the child process:
```bash
# Run a Python script or CLI command:
cloak run -- python main.py

# Run a curl command:
cloak run -- curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"

# Open an interactive subshell with all secrets loaded:
cloak run -- $SHELL
```

### 3. Retrieve or Inspect Secrets
```bash
# Masked display (safe against shoulder surfing & screen sharing):
cloak get OPENAI_API_KEY
# Output: sk-p****6789 (use --reveal to display in full)

# Reveal full value:
cloak get OPENAI_API_KEY --reveal

# List all stored keys (values are never displayed):
cloak list
```

### 4. Delete a Secret
```bash
cloak delete OPENAI_API_KEY
```

### 5. Namespaces (Environments)
Organize keys across different projects or environments:
```bash
# Save to 'staging' namespace:
cloak set -n staging DATABASE_URL "postgres://staging-db:5432"

# Run within 'staging' namespace:
cloak run -n staging -- npm start
```

### 6. Export for Shell Tooling
```bash
# Standard dotenv format:
cloak export --format dotenv

# Shell export statements (for `eval $(cloak export --format bash)`):
cloak export --format bash

# JSON format:
cloak export --format json
```

### 7. Frictionless AI Loopback Proxy (`cloak proxy` & `cloak run --proxy`)
Shield your raw OpenAI and Anthropic API keys completely from AI coding agents (Claude Code, Cursor, Aider, custom LLM tools) while supporting mid-session JIT key acquisition:

#### Option A: Frictionless One-Liner (Recommended)
Run your agent with `--proxy`. Cloak will **automatically** start the proxy daemon if it isn't running, route `OPENAI_BASE_URL` and `ANTHROPIC_BASE_URL` through the proxy, inject the ephemeral session token, and **shield the real secret keys from child process memory**:
```bash
# Zero manual setup: auto-boots proxy daemon and routes agent traffic
cloak run --proxy -- claude
cloak run --proxy -- aider
cloak run --proxy -- python3 my_agent.py
```

#### Option B: Configure Current Interactive Shell
If you prefer running commands directly in your existing terminal tab:
```bash
# Automatically sets OPENAI_BASE_URL, ANTHROPIC_BASE_URL, and session tokens:
eval $(cloak proxy --env)
```

#### Manual Proxy Control
```bash
# Start proxy in foreground (binds to loopback 127.0.0.1:4141)
cloak proxy

# Stop a running proxy daemon
cloak proxy --stop
```

**What happens when a key is missing midway?**
The proxy **pauses the HTTP request** without dropping the socket, and initiates a Just-In-Time (JIT) credential prompt in the desktop HUD or terminal:
```text
┌─────────────────────────────────────────────────────────────┐
│ [CLOAK JIT PROXY] ⏸ Request Paused: Key Missing            │
├─────────────────────────────────────────────────────────────┤
│ An AI tool or agent is requesting access to 'OPENAI_API_KEY'│
│ Enter value below to authorize & continue without restart:  │
└─────────────────────────────────────────────────────────────┘
```
In the desktop HUD, you can provide the credential and choose **Allow Once** (authorizes only the in-flight request without persisting) or **Always Allow** (securely persists to OS Keyring).

### 8. Headless / Server / CI Mode (`--store file`)
When running on headless Linux servers or Docker containers without a desktop keyring:
```bash
export CLOAK_MASTER_KEY="your-secure-passphrase"
cloak --store file set PROD_API_KEY "secret_key"
cloak --store file run -- ./deploy.sh
```
